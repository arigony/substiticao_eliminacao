# Substituição e eliminação · simulador SN1, SN2, E1 e E2

Simulador interativo para revisão dos mecanismos de substituição nucleofílica e eliminação (Química Orgânica, PUCRS). Cada etapa mostra as setas de elétrons animadas, os átomos se movendo até a estrutura seguinte e a posição correspondente no diagrama de energia.

## Conteúdo

| Mecanismo | Exemplo | Link direto |
|-----------|---------|-------------|
| SN2 | (S)-2-bromobutano + OH⁻ → (R)-2-butanol | `#sn2` |
| SN1 | brometo de terc-butila + H₂O, com etapa extra de rearranjo | `#sn1` |
| E2 | 2-bromopropano + EtO⁻ → propeno | `#e2` |
| E1 | brometo de terc-butila em etanol, com etapa extra de rearranjo | `#e1` |

Também inclui:
- diagramas de energia de uma etapa (SN2, E2) e de duas etapas (SN1, E1);
- fluxograma interativo "Qual mecanismo?", por tipo de substrato e de reagente;
- quadro comparativo (substrato, reagente, solvente, cinética, estereoquímica, rearranjo);
- desafios com correção imediata.

Para abrir direto num mecanismo, acrescente o código ao endereço, por exemplo:
`https://SEU-USUARIO.github.io/substituicao_eliminacao/#sn1`

## Como publicar no GitHub Pages

1. Crie um repositório público chamado `substituicao_eliminacao`.
2. Envie `index.html`, `README.md` e `.nojekyll` para a raiz.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e clique em **Save**.
4. Em um ou dois minutos a página estará em `https://SEU-USUARIO.github.io/substituicao_eliminacao/`.

## Uso

- **Próxima / Anterior** ou as setas ← → do teclado avançam as etapas.
- **Repetir setas** anima de novo o movimento dos elétrons.
- **Reproduzir tudo** percorre o mecanismo inteiro automaticamente.

Arquivo HTML único, sem instalação. Funciona em computador e celular, com tema claro e escuro.
